Randy Bulk SMS Sender is a Windows desktop app for sending SMS messages through a connected GSM modem. Import recipient lists from CSV or Excel files, compose a message, and review the sending results.

Download: Get the latest Windows x64 installer from the Releases (../../releases) page.

Requirements: Windows 10 or later (64-bit) and a compatible GSM modem with an active SIM card.

Install: Download and run Randy-Bulk-SMS-Sender-Setup-1.0.13.exe, then follow the installer prompts.
